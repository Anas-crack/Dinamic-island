# Dynamic Island (v1.0.6) — المطور: أنس محمد

### الجديد في الإصدار v1.0.6:
- **أزرار وقت الإخفاء التلقائي (20 / 30 / 40 / 50 ثانية / دقيقة) + شريط تحكم:** مفعّل افتراضيًا على 30 ثانية.
- **أنيميشن آيفون مرن وقوي (`OvershootInterpolator` / `AnticipateInterpolator`):** مع زر **"اختبار حركة الظهور"** مباشرة داخل التطبيق.
- **صور فائقة الوضوح (`30dp` مصغرة / `66dp` موسعة):** قص مركزي وتحجيم ناعم (`createScaledBitmap(..., true)`) بدون أي تشويش.
